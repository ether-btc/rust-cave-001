## Problem Identified

Installed `.so` was built May 10 15:23 but source fix was committed at 15:39.
Two bugs in the installed .so:
1. `normalize_tense` was stripping "ed" from verbs after active voice transform
   (e.g., "made" → "mak", "created" → "creat")
2. Agent regex used `(\w+)` — single word — so "the team" was captured as just "the"

## Fixes Applied (src/lib.rs)

### Fix 1 — Multi-word agent regex
Line ~133: Changed agent capture from `(\w+)` to `(.+)` to handle multi-word agents.

```rust
// Before:
r"(?i)\bThe\s+(\w+)\s+was\s+(\w+)\s+by\s+(\w+)"
// After:
r"(?i)\bThe\s+(.+?)\s+was\s+(\w+)\s+by\s+(.+)"
```

### Fix 2 — Added "sung"→"sang"
Line ~112: Added `("sung", "sang")` to verb_conjugations map.

### Fix 3 — Disabled normalize_tense
Line 207: Commented out `result = normalize_tense(&result)?;` — the function
corrupts verbs without a proper verb DB. `#[allow(dead_code)]` added at line 161.

### Fix 4 — Removed debug output
Removed `eprintln!` and `std::io::Write::flush` calls from `preprocess_text`.
