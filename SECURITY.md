# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please open a GitHub Issue with the label `security` or email the maintainer directly. Please do not disclose security issues publicly until a fix is available.

We aim to respond to security reports within 48 hours and will work with you to understand and address the issue promptly.
