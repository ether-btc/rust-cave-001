## What's in v0.5.0 + v0.6.0 (vs PyPI v0.4.3)

### Security Hardening (v0.5.0 from `CYCLE3_INTEGRATION_SECURITY_AUDIT.md`)

- **SEC-1:** `compress()` validates input header, uses explicit constants
- **SEC-2:** `decompress()` validates input header, rejects zero size
- **SEC-3:** `compress()` enforces input size limit (DoS prevention)
- RUSTSEC advisories: upgraded pyo3 0.24.2 → 0.29 (fixes RUSTSEC-2026-0176, RUSTSEC-2026-0177)

### MCP Server (v0.6.0)

- New `caveman-mcp` entry point in `pyproject.toml`:
  ```toml
  [project.scripts]
  caveman-mcp = "mcp_server.server:main"
  
  [project.optional-dependencies]
  mcp = ["mcp>=1.0.0"]
  ```
- Allows Caveman Compression to be used as a Model Context Protocol tool server
- Compatible with any MCP-compliant client (Hermes, Claude Desktop, etc.)

## Installation

```bash
pip install rust-cave-001          # core library
pip install rust-cave-001[mcp]     # with MCP server support
caveman-mcp                         # start MCP server
```
